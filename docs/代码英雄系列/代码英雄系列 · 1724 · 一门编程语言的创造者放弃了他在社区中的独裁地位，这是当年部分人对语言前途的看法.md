## 总结

- Python 创造者 Guido van Rossum 在 2018 年因感到决策压力过大而宣布卸任 BDFL（仁慈独裁者）职位，震惊了社区，引发了对开源语言治理模式的深刻反思。
- Python 因设计上的可扩展性（如 C 扩展）和“全谱语言”特性，在数据科学、Web 开发和机器学习领域爆发式增长，成为最受欢迎的编程语言之一。
- Python 社区强调包容性和多样性（如女性核心开发者和行为守则），被认为是其长期健康的基石，而 van Rossum 的个人推动对此功不可没。
- van Rossum 卸任后，社区通过建立五人指导委员会（包括 van Rossum 本人）来继续决策，解决了此前因独裁决策模式导致的运行停滞问题。
- 语言早期需要“仁慈独裁者”式的强有力领导以确保方向，但成熟社区最终必须自行接管发展，这是编程语言未来共同的挑战。
