## 总结

- 操作系统战争从桌面端转向企业服务器市场，互联网的兴起和开发者需求是这一转变的核心驱动力。
- Linux 起源于莱纳斯·托瓦尔兹等开源叛逆者，其开放特性和命令行魅力吸引了大量开发者，并逐步在服务器领域崛起。
- 微软等专有软件巨头曾试图通过 FUD（恐惧、不确定、怀疑）等手段打压 Linux，但未能阻止其发展，最终 IBM 等大企业的投资确立了 Linux 在服务器市场的主导地位。
- 智能手机时代，基于 Linux 的 Android 系统取得了巨大成功，进一步压缩了微软在移动端操作系统的生存空间，迫使微软进行战略调整。

- 当前战争已转移至云端和人工智能平台，开源成为公认的主流模式，其分散、协作的本质使其难以被单一公司控制。

greg crow hartman是linux基金会的成员，每个公司和每个人都以自私的方式为Linux做出贡献。他们这样做是因为他们想解决问题，他们已经在硬件上不起作用了，或者他们想添加一个新功能来做其他事情，或者想把它带到一个会建立的方向，他们可以用于他们的产品。这很好，因为这样每个人都从中受益，因为他们正在释放代码，所以每个人都可以用它。所以正是因为这种自私，公司和所有人都有每个人的利益。
