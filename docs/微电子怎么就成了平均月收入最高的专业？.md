# 微电子怎么就成了平均月收入最高的专业？

## 总结

- 微电子科学与工程成为2025届本科生平均月收入最高的专业，月均7814元，但该数据主要反映行业下游和制造岗位，IC设计岗薪资更高。
- 微电子专业薪资排名自2017年纳入榜单以来持续上升，主要受益于国产替代化趋势。
- IC设计岗位分为数字IC、模拟IC、射频IC和SIPJ四大类，各岗位的薪资、门槛和竞争情况差异显著。
- 数字IC岗位（设计、验证、后端）普遍待遇优厚，但验证岗因转行宣传而竞争激烈，后端岗则面临加班压力。
- 模拟设计岗门槛高但供给少，模拟版图岗门槛较低但技术天花板和薪资上限有限。
- 射频IC和SIPJ岗位需求少，多为军工或研究所去向，薪资不高但稳定性强；EDA和AE/FAE岗位各有特点，入行需谨慎。

### 1. 微电子专业为何成为平均月收入最高的专业？

嗨大家好，老张。那本期呢，我们就来从夯到拉锐评一下IC设计行业秋招的这个岗位分类。为什么要干这个事呢？因为微电子已经成为了平均月收入最高的专业了，没错我绷住了。就在上个月，麦克斯研究院发布了2026年本科生就业报告，那这个就业报告呢，也就是2025届的本科生在毕业半年之后，他们展开了一个调查。那这个调查结果呢，就是平均月收入最高的专业已经成功的变成了微电子科学与工程。呃，不知道你们怎么看，反正我觉得啊，勉强合理吧，勉强合理。就虽然说统计学自有它的门道在，但是这家机构的蓝皮书已经是国内一众的搞这种事情里面相对比较靠谱的了。那不吐槽这个结果，我们先来看具体的数据：微电子专业平均月收入在7814元啊，有零有整，随后分别是电子科学与技术、自动化以及信息安全。坦白说这个7814元这个数字，如果你单独拎出来跟芯片行业上游设计，亦或是中游制造的绝大大多数岗位去相比的话，其实它并不算高，但如果你能够把全行业的所有岗位都统一拿出来，然后再一平均的话，这个数字就还不错。

而且离谱的事情在于，自从2017年就这个榜单把微电子纳入这个排行之后，那微电子的排行一直在上升。18年的时候排在第九位，21年的时候排在第八位，22年的时候排在第六位，23年和24年的时候都排在第二位，直到25年成为了新的本科高薪专业啊，第一名。那关于微电子专业为什么能够一路高歌猛进，呃，其实五个字就能回答啊——国产替代化。那这里就不赘述了。

### 2. 为何要锐评IC设计岗位？AI排行不靠谱

那开头说了啊，今天主要是想从夯到拉锐评IC设计行业秋招诸多岗位，因为真的就是每年都有那么一批对于行业完全不了解的同学来问你那些你觉得是常识的东西。举一个比较夸张的例子吧，啊，某天晚上连麦一跨物的硕士都快毕业了，连IC设计你这个上游环节上都有哪些岗位都是不知道的。一开始呢我其实是觉得这种问题呢你问问AI也差不多，但是呢前两天我自己试了一下，就我让AI去做一个什么呃从夯到拉的这样的一个锐评，结果AI给出的排行，他把射频IC排在了最夯的位置上，我绷不住了。只能说在目前这个阶段，呃，某些细分的行业，再到他具体的岗位上的一些细节，你指望AI还是呃有那么一些不靠谱的，你可能需要多方验证。

那事先声明，我所谓的从夯到拉锐评这些岗位，只是我个人视角下对于IC行业上游设计这个环节上诸多岗位的大致的分类啊，不可能说是要细化到不同赛道上的差异化的岗位上面，而且制造呀封测再往下有，我就不太清楚了啊，建议去看啊这位up主的视频。首先市面上IC设计的就业方向可以粗略的分为四大类，也就是数字IC、模拟IC、射频IC、SIPJ。

### 3. 数字IC：设计、验证、终端、后端哪个最夯？

那数字IC的就业岗位又可以分为数字前端、数字验证、数字终端以及数字后端。那先来看数字设计啊，我直接给到一个夯。虽然他学历门槛要求高，且卡科班，且要求你能力突出，但是呢他确实是呃岗位鄙视链顶端的存在啊。当然具体有没有这个岗位鄙视链我不太清楚啊，有些人说有些有些人说没有，这个并不是我自己造出来的啊。并且会因为他严苛的科班要求而避开了那些其他专业转行过来的那么一大批人的竞争。那这个岗位的校招薪资区间呢应该是25~50之间，这里我们就不讨论什么SSP这种情况了。但一旦你拿到这个岗位的话，年包如果是少于30万，你要么就找的是初创公司、小公司，你可能博一个可能性，你要么就是找的是外企啊，图一个work life balance。

那IC验证呢，我这里给到顶级原版呢。它是跟IC设计一样的情况，也分不出个孰高孰低，但是呢就是因为前些年某些机构的宣传宣传，什么专业都能转IC验证，IC验证就是很好转呀，导致呢这个岗位上卷的程度过头了。同样的薪资区间，但是他的竞争压力反倒是压过设计一头的，所以这里只能给到顶级。数字终端这个就不太好评了，因为并不是所有的公司都会设置终端的这个位置，一般设置比较多的是DFT。那有时候有些公司也会把综合或者是什么SAT划到终端，那这里我只谈DFT的话，我可以给到一个顶级，不过之前已经讲过这个岗位很多次了。

他啊，他是一个比较吃学历配置的岗位，所以对名校的同学来说，他是占很大优势的顶级岗位。那对于学历背景不是那么好的同学，那他的入行难度还是挺高的。那最后呢则是数字后端啊，我原本也想给到顶级的，但是随着我认识的那些IIC后端的朋友跟我分享他们的工作日常，就那么几个人，他们都会说后端的加班压力是最大的啊，又苦又累。因为我不太确定是这几个朋友自身情况特殊，还是说所有公司都存在这样的情况。那如果是前者的话，那额数字后端它的入行难度、竞争压力会比验证小一点，但是薪资区间呢又跟验证设计差不多，所以说给到顶级是没有问题的。但如果确实是绝大多数的公司的数字后端都这么苦、这么累的话，那只能给上一个人上人了。

### 4. 模拟IC：模拟设计与模拟版图的差距

在数字IC这一块，你如果不考虑不同公司加班程度的差异化的问题，只看工作内容、工作环境和薪资待遇，其实都是可以给到顶级及以上的。因为目前IIC设计行业，市场上的岗位可能甚至六七都是数字IIC呃，我可能还说低了。那剩下的两成呢是模拟IC，再剩下的合起来可能才是射频和FGA。那下面就说模拟IIC模，那模拟IIC这边就分为了模拟设计和模拟版图。模拟设计呢依旧是可以给到行啊，依旧是学历门槛高，且要求科班，且要求能力突出。唯一不好的一点是岗位供给不是特别多，不过好在啊，国内这个方向的老师也不是特别多，也就是每年毕业的模拟方向的学生也就那么点。而且模拟设计的薪资上限也会略微比数字设计再高那么一点呃，它未来可以上升的天花板也要微微的那么高那么一点，但也都是微微高一点，也没有高特别离谱的。

那模拟版图呢只能给到NPC了，因为这个岗位要求的学历门槛并不是特别高，甚至在前几年大专的同学经过一段时间的培训也能够比较顺利的上手。不过这两年嘛啊学历内卷很多，九二这个本科同学也会考虑这个岗位。我虽然之前一直会说这样的情况他不是特别好，但只要你自己能够接受这个岗位的技术天花板不高，其他的薪资上限要远低于上面的那些设计岗位，对你只要能够接受，他就还是不错的岗位，至少跟其他专业的工科去向相比的话，确实还不错。

### 5. 射频IC与SIPJ：高门槛但岗位稀少

那最后的射频IC，可IPJ其实可以放在一起讲啊，都是只能给到人上人的级别。虽然同为设计方向，但是这两个呢在市场里的岗位需求他确实不是那么的多。IPJ呢，很多大公司或许还是会在某些部门设置额怎么不多的几个岗位，但是射偏C这一块呢，真的就是除了啊少得可怜的一些公司，他会设置某些额竞争难度也极高的部分待遇还不错的岗位之外，剩下的基本也都是去什么国企、去什么军工、去什么研究所了。那这方面的去向呢，你问问你们师兄师姐应该就清楚了，待遇不会很高，但是呢加班强度也挺大的。不过再怎么说呢，这两个方向它依旧是高技术门槛的这种行业本身呢也没有这个中年危机的担忧，所以人上人还是有的。

### 7. 从岗位薪资看行业现状：7814元背后的真相

可能拿到30万，你拿到这个FAE的岗位，可能也就20到25万吧。但是随着你在岗位上的项目积累、人脉积累，那后期啊这个岗位的成长速度还是挺快的，对后期还是可以给到定期的。所以对这种盘下来，如果你要单论IIC设计呃，整体的这些岗位的平均月收入，显然是要比那个7814要高出一大截的。

但他那个报告说的又是本科生，问题来了，IIC设计行业，绝大多数的岗位的学历要求都是硕士啊。虽然说近几年有这个本科生就能干一些设计岗的这样的例子，但是也没有那么多。所以说那个7814那个数字应该是除开了IIC设计行业的绝大多数的技术岗，然后剩下的岗位跟制造那边，大多数的岗位跟风尚那边，大多数岗位平均下来一个数字。在这个行业的中下游，拎出来都能排出一个第一了。某种意义上，也就更能够说明目前这个专业在风口上的含金量啊，更能够说明啊，很多IC人看不上的fab厂的一些岗位，放到其他这种生化环材的天坑专业眼里，已经是他们觉得很好很好的选择了。
