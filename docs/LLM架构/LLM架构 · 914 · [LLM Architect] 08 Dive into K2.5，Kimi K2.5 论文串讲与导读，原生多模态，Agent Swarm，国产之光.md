## 总结

- K2.5 是基于 K2 的持续预训练模型，新增 15T 图文联合数据，强调原生多模态而非 vision adapter，早期引入图像数据能同时提升文本和视觉能力。
- Zero-Vision SFT 只使用纯文本数据即可激活视觉 agent 能力（如像素操作、定位、OCR），通过 IPython 程序化矩阵操作迁移到图像任务（如走迷宫）。
- 联合图文 RL 按能力而非模态组织数据，使用 outcome-based reward 和 GRM，显著提升视觉定位、表格理解等能力。
- Agent Swarm 训练的是 Orchestrator（可训练）而非子代理（冻结），通过并行度、完成率、Task-level outcome 等 reward 设计，并引入关键步骤度量分解质量。
- Policy Objective 与 GRPO 有三个差异：advantage 计算只减均值、clip 机制与 advantage 正负无关、KL 惩罚使用 K2 估计，用于缓解 off-policy 问题。
- 推理框架采用纯 token in token out 模式，强调使用 response id（token id）避免编解码非对称性导致的序列不一致。
