## 总结

- RoPE通过将Q和K向量按维度分组旋转，不同子空间对应不同旋转频率（theta_j指数衰减），从而同时编码短距离和长距离依赖。
- 高频维度（左侧）捕捉短距离依赖（如语法、词组搭配），低频维度（右侧）捕捉长距离依赖（如语义、指代），实现了多尺度位置编码。
- attention score公式推导得出：score = 语义相似度（Q·K）乘以位置衰减系数cos((m-n)*theta_j)加上正交分量。
- RoPE存在长距离衰减特性：远距离时高频维度正负抵消（波的干涉效应），低频维度缓慢下降，最终attention score随距离增加而衰减。
- 以base=10000为例，理论最大context window约为62,800个token（最低频维度旋转完整一圈的距离）。
- 该衰减特性是位置的先验，无需学习参数；embedding维度不影响趋势，base值才影响实际衰减速率。
