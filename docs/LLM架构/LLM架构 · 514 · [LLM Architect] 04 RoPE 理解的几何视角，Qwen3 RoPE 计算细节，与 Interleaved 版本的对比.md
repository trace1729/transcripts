## 总结

- RoPE通过绝对位置编码的旋转矩阵，利用旋转矩阵的数学特性（R_M^T R_N = R_{N-M}），隐式实现相对位置编码。
- 从几何视角理解RoPE：embedding维度按子空间分组，每个子空间有独立的频率θ_i（由base决定），低维子空间频率高（波长短），高维子空间频率低（波长大），从而同时编码短程和长程位置关系。
- 用可视化展示不同子空间（如第0、8、64个）的cos值随位置变化的差异：低频子空间（如第64个）变化缓慢，高频子空间变化剧烈。
- 对比了Qwen3实现的RoPE与经典Interleaved（复平面）版本的差异：Qwen3使用实数域旋转矩阵，通过拼接、复制和rotate half操作进行分组，分组方式为[0, d/2]配对，而Interleaved为[0, 1]配对，但两者数学上等价。
- 展示了Qwen3源码中RoPE参数计算（theta、cos、sin）和应用（rotate half）的细节，并验证了实数矩阵与复平面实现在计算上的等价性。

### 4. 2D平面旋转策略与高维空间的子空间切分
