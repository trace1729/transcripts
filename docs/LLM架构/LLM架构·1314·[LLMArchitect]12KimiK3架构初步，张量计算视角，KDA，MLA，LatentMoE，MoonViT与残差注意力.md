## 总结

- Kimi K3 模型共有 93 个 layer，每个 layer 由 attention（KDA 或 MLA）加 MoE/FFN 构成，可通过 23×3+1 或 7×12+9 两种算法分解。
- KDA (Kimi Direct Attention) 是一种基于 RNN 式递归的注意力机制，通过遗忘门 alpha 和写入门 beta 递推状态矩阵 ST，无需显式位置编码。
- MLA (Multi-head Latent Attention) 通过压缩 KV cache 至低维 latent 空间，再投影回高维进行标准 attention 计算，同样不使用旋转位置编码。
- Latent MoE 首先将 token embedding 降采样至半维 (3584) 作为专家输入，通过路由选择前 16 个专家，每个专家为 up-gate-down 结构，另有共享专家处理原始维度输入。
- MuonViT 将图像切块 (patch) 并添加 2D RoPE 位置信息，经 27 层 full self-attention 编码，再通过 2×2 融合将 10764 个 patch 合并为 2691 个视觉 token。
- 残差注意力 (Residual Attention) 将 RNN 的 token 级循环旋转 90 度应用于 layer 维度，使当前层的 hidden states 成为之前所有层输出的加权和。
