### 2. 何谓专家混合：从参数规模到稀疏激活的架构解释

首先让我们了解这个模型的本质。关于参数规模，我认为两万亿参数对非深度学习专家来说意义不大。Transformer模型、注意力机制，所有这些内容，如果你只是随意编码或为工作构建代理，我认为理解这个概念层面就足够了。或者如果是专家请阅读本视频中的论文。我们只需帮助你理解开源模型的基本原理，比如Kimi在理论上表现非常出色，我们当然会在真实系统中进行测试。

就像我们之前展示的开源项目，OE代表专家混合。那么什么是专家呢？你可以想象Kimi K3模型是一个拥有两千亿参数的大脑，而参数就像大脑中的神经元，负责进行某些计算，并做出一些估计，存储一些数值。然后当这些神经元相互交流时，这就是大脑实际运作的方式。同样在大型语言模型中，这些携带权重或参数的节点在进行通信，最终将查询结果输出到最终答案。比如昨天英格兰和法国的比赛谁赢了？显然是英格兰，比分是多少对吧？它可能做了很多处理，搜索网络调用部分内部知识，最终给出答案。这就是大脑的工作原理，同样地，这就是语言模型的工作方式。

但问题在于，如果大型语言模型仅通过规模扩大就能表现优异，为什么不做一个一百万亿参数的大脑？这是因为会变得极其缓慢。从数学角度而言，你不希望所有参数或神经元同时激活。在K3模型中只有五十亿参数处于活跃状态。大型语言模型的工作原理是检查你发送的句子，然后将每个词与其余词汇逐一比较。如果句子有十个词，这意味着每个词都需要计算相关性或与其余九个词的关系，总计算量将是十次重复直到结束，因此总共有百次，即十的平方。本质上计算是当有两个x词时，计算量会是四倍x。你可以看到我在这里画了很多点，想象这些只是参数。

Kimi模型处理的方式是，这实际上是在说，而不是让整个大脑在功能上全部活跃，同时我们总共有八百九十六位专家，每次提问时只有十六位会处于激活状态，因此模型实际上非常稀疏。因为当它是k2模型时，他们有三百八十四位专家，每次只有八位会处于激活状态。现在理论上将这种稀疏性翻倍，这种架构的优点在于在进行注意力计算时，在权重处理上能节省大量时间。这应该是一种更可扩展的未来方案，只要唤醒机制或专家切换机制能快速完成。

### 3. Delta注意力：用滚动平均解决二次方复杂度瓶颈

意味着现在我正在问关于我早餐该吃香蕉吗，下一个问题是关于比赛结果的，这些从语言模型视角使用了完全不同的专家，并希望模型能立即响应，哪个专家现在应该唤醒哪个专家来运行这个大型语言模型，这就是Kimi模型正在做的事情。这是第一点。第二点非常重要，称为Kei Delta注意力。你可能听说过深度神经网络，没错，这意味着神经网络，你会发送输入并期待输出，中间有多个神经网络层。

这些层需要传递记忆或注意力到下一层，以便在信息处理更抽象时能够知道应该关注哪部分、哪部分可以忽略。当神经网络过大时这会变得非常复杂，拥有两万亿八千亿参数的情况下，Kimi的做法是不再这样做，而是创建了新的Delta注意力机制。基本原理是当有百万级上下文时，可以以线性注意力成本处理。我并非这方面的专家，所以我向Claude寻求答案。Claude的回答非常明确：它指出对于每个词，注意力机制始终会询问每个其他词与我的相关性，将其转化为权重，然后对值进行加权求和。好的，所以这是一个n平方问题。没错，十的平方是一百。Kda会递归计算相同内容而非重复计算。好的，这到底是什么意思？这意味着你不会通过重新汇总所有数据来生成一个表情包，它将运行一个逐步更新的均值，这是一种指数加权移动平均。

这些都是数学和理论细节，但你需要知道的是他们以非常创新的方式实现了这一点，利用这些人的研究成果。所以在计算权重时、计算注意力时，是以线性方式完成的，而非n平方。简而言之，Kimi Delta注意力是像滚动平均数一样计算的，而非重新汇总所有内容。每一步大家还跟得上吗？别走开，就是这样。这是你需要掌握的两个核心概念，大致理解为何Kimi的新模型能表现如此，尽管模型参数数量巨大。好的，还有一些要点：该模型适用于循环，当模型在上次循环中见过某些标记时，会复用之前的工作而非重新计算，使其成本降低十倍。我知道这听起来很理论化，但这非常重要。如果你在构建智能体，亚洲循环几乎重置相同上下文，每次迭代都会如此，会将全部之前的对话传递给语言模型，这会浪费大量token和金钱。但最后K3，正如他们所说，比Opus 4.8和GPT 5.5更便宜。
