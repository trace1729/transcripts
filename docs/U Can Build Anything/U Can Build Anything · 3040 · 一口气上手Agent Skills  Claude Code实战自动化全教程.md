## 总结

- Agent Skills（代理技能）是一种通过定义技能文件（如 skill.md）来指导 AI 处理信息的机制，它包含元数据（名称、描述、触发条件）、指令主体和资源部分。
- Agent Skills 与 MCP 的区别在于，MCP 用于获取外部数据（如从 Notion 读取信息），而 Agent Skills 则专注于定义如何处理这些数据，使其更符合个人或特定任务的需求。
- 技能文档的结构包括元数据（用于 AI 识别和触发）、主体（具体指令和步骤）以及资源（如外部脚本文件），资源可引用代码来执行额外任务（如将摘要导出为 HTML 网页）。
- 通过实际销售对话摘要的演示，可以看到技能能够将原始聊天记录转化为结构化的主题、决策、行动项和截止日期，有助于高效处理大量重复性任务。
- 开发者案例展示了如何使用代理技能自动完成新项目的初始化配置，包括设置项目结构、环境变量和数据库，减少了手动重复操作。
- 在 RAG 后端搭建示例中，通过 Agent Skills 自动生成项目代码、创建数据库表、填充数据并测试功能，实现了从零到一的完整自动化流程，证明了该技术在加速开发和运营流程上的潜力。
