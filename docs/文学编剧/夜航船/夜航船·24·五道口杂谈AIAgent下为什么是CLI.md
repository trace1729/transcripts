## 总结

- MCP 存在客户端依赖、上下文浪费、工具冲突和安全隐患等致命问题，导致其被 CLI 逐步取代。
- CLI 因模型训练语料（GitHub/Linux）和 Agent runtime 环境而天然适合 AI 调用。
- CLI 采用渐进式披露，如 `--help` 和示例，占用上下文极少，不干扰模型专注力。
- 相比 MCP 的 JSON 模式，CLI 允许模型直接输出命令字符串，简化了 function call 流程。
- 未来趋势可能向云端 Agent 发展，但 CLI 在近期仍是确定性的趋势，建议用户直接使用官方 CLI 并搭配说明文件。
