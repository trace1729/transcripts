# 【探索·发现】华罗庚（8集全）·P6（六）大哉为用

他决心闯出一条路来，研究适合中国国情的应用数学。他为此两度致信毛泽东主席，得到了热情的鼓励。他到西南铁路建设工地开办了我国的统筹法学习班，他还走进了云贵高原的深山野岭之中。请收看探索发现即将播出的八集电视人物专辑片《华罗庚》第六集，大哉数学之为用。1953年，中国科学院组团赴苏联考察，和物理学家钱三强任团长，团员中包括华罗庚与大气物理学家赵九章，以及从清华大学毕业不久的何作修等二十多人。

那个仿佛代表他一共三个月，我讲得很坦诗火山上一个月。华罗庚在图中所做的一幅对联至今传为佳话，华罗庚诗文选是这样介绍的，图中无事，华罗庚以三强韩兆卫为上联，请别人对下联。无人应对，华罗庚乃自对下联，九张高谷弦。上下联都是一语双关，特别是下联，一是指赵九章，二是指首次记载《勾股弦定》里的中国古典数学名著《九章算术》，两相结合十分出彩。

然而，作为亲历者，合作修说，华罗庚的这幅对联曾经有过一番推敲的过程，难就难在上联。他告诉我，不是三强韩藏卫，三强苏美英或者叫三强美英苏，九章勾苦学，所以他下年他早想好了三强苏美英，他说小河这个也有点问题。我现在要把这个苏联说成最强啊，这个好像也不大符合事实，但是我要给他倒过来，这个美英苏这更不好，美苏英把英跟美分开了也不好，后来他说叫三强韩兆卫嘛，战国七雄我说这个好，政治上也妥善，所以是先有下点再有上点。

其实对于苏联科学技术的状况，华罗庚早就实地领教过，七年前他只身一人应苏联科学院和苏联对外文化协会的邀请，曾到苏联访问过三个月。他对数学在苏联广泛受到重视的程度深有体会，在《访苏三月记》中他有这样一段感慨，我想到我们中国科学界的情形，中国有一般人认为数学无用。也有一些数学家自己对数学研究的很好，但总觉得数学无用武之地，其实是因为没有中间的这一道桥梁，把数学和应用连接起来。在某种意义上讲，纯粹数学是一种文化，即使科学也是文化，它不会被产生死疾的症是比较简洁的。

然而华罗庚早就看好应用数学了，他曾呼吁过，我们中国科学要想进步，除去必须注意到理论的研究之外，还需要注意到理论和应用的配合，如何走到这一步呢？这在国际数学界上缺乏合乎中国国情的先例，即使被奉为学习榜样的苏联，也没有现成的模式可供照搬。华罗庚决心闯出一条路来，五八年华罗庚提前转向搞应用数学，那么大家对华罗这种转向是不理解的。为什么呢？说已经是一个大数学家，纯粹数学已经搞到顶峰，许多都是在国际的理论数学家的这个行列上了，为什么要转过去呢？连国外的许多数学家评论都说，华罗庚如果在国外继续做他的那么对数学的贡献就更大。华罗说，我原来就有个蓝图，我的蓝图当中就包括应用数学。

1958年是个非常的年代，许多科学家纷纷走出研究所和高等院校到生产实践中去寻找课题。华罗庚来到北京顺义县农村，研究打麦厂最合适的位置，因此他还欣喜地写了《数学入田间》这首诗。请注意其中的规划二字，这是全诗的关键词，全称因为线性规划属于运筹学的范畴。王源在《华罗庚》这本传记中写道，1958年当数学界掀起理论联系实际、数学直接为国民经济服务之风时，长期在纯粹数学中按传统方式工作的数学家确实是茫茫然而手足无措了，线性规划就像一道闪电打开了中国数学家的眼睛，居然数学能够直接为国民经济服务。这个时候他选择最先是选择了先行规划这个领域，先行规划领域他曾经率运民意啊、吴芳啊、王源啊这些下到国民经济的一些部门，特别是运输部门搞运输，出了不少成就。

1959年，华罗庚与王源合作写了一篇专论，提出了利用分元玉的独立单位系来构造多重定积分的求积公式，国际上称之为画王方法。你看，华罗说是你不会用，但是你要怎么用，你都拿出个样板出来了，这是王源发现有用，他马上肯定，一看之后，我马上写了一篇文章，在科学通报上发了，大肆赞扬这本书。后来，日本数学家告诉华罗庚，画王方法很成功。国外还有评论文章认为这些工作对整个理论是价值连城的贡献。而在1959年里，华罗庚先是在光明日报发表文章数学与应用，紧接着又在人民日报刊登大灾数学之为用。

进一步论证，数学是一切科学得力的助手和工具，它有时由于其他科学的促进而发展，有时也先走一步领先发展，然后再获得应用。让数学先走一步领先发展，这无疑是华罗庚向自己提出的挑战。如果说他在1960年发表的运筹学论文是将数学理论研究用于国民经济生产实践尝试的发端，那么他的下一个步骤又是什么呢？他最大的思维和最大的心愿是要想构建适合中国国情的中国管理科学，让中国经济建设管理成果上到一个更高的层面上。所以他的胸怀是非常的宽广，眼见是非常的高。华罗庚看到了线性规划以及矿体几何学的局限性，他所祈求的显然是行之有效而应用更为广泛的方法。那又是怎样的方法呢？

1961年夏季，中国数学会在北京颐和园龙芒庙分别召开了受到冲击与破坏几乎被取消的数论、拓扑学和函数论等几门学科的全国学术会议，统称龙芒庙会议。华罗庚虽然参加了会议但发言不多，他的想法在会后不久，他以全国人大常委身份赴江苏视察工作期间时有闪现。他来到了金坛，这是新中国成立后他第一次回到家乡。在母校金坛中学，他向师生做了天才由于勤奋、聪明在于积累的讲话，介绍数学是一门非常有用的学科，是一切科学的有力助手，对建设祖国很有用处。两年后，华罗庚以全国人大常委身份再次到江苏视察，顺道回了一趟家乡金坛。在家乡人的眼中，华罗庚平易近人、谈笑风生，但他们并不知道此时的华罗庚正承受着很大的压力。

就在来到江苏之前，华罗庚曾到北京的一家工厂尝试以最少的试验次数迅速找到生产和科学实验的最优方案的一种数学方法。然而，几个月下来成效甚少，遭到一些人的非议和反对，有人甚至幸灾乐祸。华罗庚这样做是沽名钓誉、哗众取宠。这些方法曾使北极星导弹的研制时间大大缩短。他把这种方法取名为统筹法，同时又在北京图书馆读到威尔德的名著优选法，这里面讲的斐波那契方法与黄金分割方法都是指导人们以最少数的实验以得到最佳工艺的一种有效办法。从生产工艺上还是搞优选法，这个生产管理上搞统筹，比较适合于这个一般的工人或技术员来掌握这些东西。这两样东西也是在运筹学里面很重要的两个分支，但是在国外因为他用那些东西都讲的比较深，华先生把他深入浅出，把他简化成优选法和统筹法这两样东西来便于大家接受。

在1964年初，鼓起勇气给毛泽东主席写了第一封信，大意是1960年以来，在国外由于计算机的出现，应用数学开始渗透到各个领域。从对已收集到的几百份国外应用数学资料进行理论计算，如果在实际工作中推广应用优选法和统筹法，可以使管理工作改变面貌，有利于提高效率。最后附上了他读了毛泽东的诗《七律·贺郭沫若同志》后作的《西江月词》：深深白骨堆中，是俺生身所在，皮囊纵然千般矮，几够一人身脉。妖性一受蛊惑，封起帐幕尘埃，亲血毛柱托翻胎，方能入得门来。

华罗庚先生，诗和信已经收读，壮志凌云，可喜可贺。华罗庚一扫往日的潮汐，他决心沿着理论联系实际为工农兵服务的道路继续向前走，他不止一次地谈到：我在日常繁忙中搞些工作，开始于1958年，但真正开始却是1964年接受毛主席的亲笔批示后。在南京师范学院做报告时，他又说道，提起统筹法，这里还有一段小故事。一位日本朋友送给毛主席一份礼物，其中有一本书的第一页，指明要给华罗庚看一下。我看后经过琢磨并结合中国的国情开始了推广统筹法的实践活动。统筹方法是一种为生产建设服务的数学方法，是想为毛主席所提出的统筹兼顾的全面统筹原则做一个小小的注脚。

华罗庚提到的那本书名为《系统理论与系统管理》，该书由美国华盛顿大学的三位教师合著，介绍了一种战略思想——系统理论。虽然内容涉及的范围极其广泛，但只是概括性的论述，丝毫也没有谈到具体问题。华罗庚告诉国家科委的领导，我们不能从中找到任何关于如何做好计划管理工作的实际而有具体的指示。为了把方法交给群众，华罗庚仔细阅读了该书及许多相关文献，结合以往数学应用的时间，敏锐地感觉到其中有许多对我们国家的生产建设有用的东西。于是，经过思考、提炼、浓缩，即意起稿。

为了把方法交给群众，华罗庚仔细阅读了该书及许多相关文献，结合以往数学应用的时间，敏锐地感觉到其中有许多对我们国家的生产建设有用的东西。

于1965年3月写出了通俗易懂可操作性强的统筹方法平话，这就是最早最大的统筹方法。用了他的思想重新写这些东西，这些东西不是翻译也不是什么抄之类的事情，而是一种再创造。油印本的统筹方法平话被送到了中科院、国家科委、经委以及更高的一些相关领导人的书桌上，引起了广泛关注和支持。听到知道了，然后就邀我父亲去上他家谈一谈，上他那去谈一谈。郭维城呢，他因为当时正在负责成昆铁路的修建，希望能够修得多快好省。后来我父亲就带了两个助手去了，把统筹图往地下一摊，然后就跟他讲怎么回事怎么回事，讲了十几分钟完了。我父亲当时因为头一次做这事，心里可能还有些不安，说我就这么点东西，不知道你听懂没有，到底有用没用。郭维城当兵出身了，他很干脆说，你这个东西大概我听懂了，你这东西就是因为少简单才好。因为如果你讲太复杂的东西，第一我的干部长没时间听，第二也可能听不懂。

1965年5月3日至5月7日，西南铁路建设工地指挥部在贵州安顺开办了我国第一个统筹法学习班，华罗庚担任主讲。接着，华罗庚应国家科委和北京市委邀请，分别在科协礼堂、建功部礼堂先后两次做介绍统筹方法的普及报告。6月6日，人民日报全文发表华罗庚执笔的统筹方法平话。6月7日，国家科委研究决定在中国科技大学成立统筹法研究室，由华罗庚主导，设在中科大应用数学与计算技术系。华罗庚在北京友谊宾馆举办统筹法学习班，将统筹法向更大的面上进行普及，形成了一整套大搞群众运动普及统筹法的行之有效的办法。7月，统筹方法平话及补充一书出版发行。

西南三线铁路指的是成昆、川前、桂昆三条铁路线，其中连接四川省会成都和云南省会昆明的成昆铁路，全长1083.3公里。1958年北段开始施工，以后几上几下。到了1964年，仅建好成都至青龙厂61.5公里。1964年第四季度，西南铁路建设大会战，西南三线重新开始建设，数十万军民摆开了战场。工地上条件恶劣生活艰苦，华罗庚提出要实地指导运用统筹方法，让人不能不为他担忧。有很多人劝他不要去的，一个你年纪大了，你不要去那儿太艰苦；第二个你腿不好不方便；第三个哪些工程师你不懂，你去你怎么办。

花了这三条的回答，对我这辈子简直是基本上就当成座右铭。他对这三个短处，得出结论截然不同。你不是劝我不去吗？他觉得你就不是了。他说我年龄了，明年比今年一定大一岁，你现在不去啊，我就更以后绝对去不了。我身体腿不好是脑毛病，肯定一年不如一年，一年不如一年，就去不了了，你现在不去，以后更去不了。第三条你不懂，他回来跟你讲，不懂我不能学吗？于是三线铁路建设的工地留下了华罗庚的足迹，他走进了云贵高原的深山野岭之中，先后到了正在艰苦施工的坠角、梅花山、石门、海骆驼、冲二梯岩、天生桥、老虎嘴、狮子口等工地。

与工程技术人员和领导座谈了解情况，在泥水中步行到罗纳隧道、花瀨二号隧道、梅花山隧道前沿探望施工现场。华罗庚的出现给战士和员工们很大的鼓舞，而战士和员工们的艰苦奋斗、无私忘我的精神又深深感动了他。华罗庚感叹，现场参观前后，我认识上有了根本的变化，前一段是纯理性加一些臆测的东西，但看了现场之后，情况完全不同了。这方法变得活了，有生命力了。华罗庚深有感触地说，这是在书斋里教室里如何设想也设想不到的东西。

他不但义无反顾地投入了统筹法的实践，而且还决心推行优选法。有一次他在报告里讲课的时候，他就提到的那个例子，修成昆铁路的时候，当时就有一个什么问题呢，就是爆破炸石头经常有伤亡。说有一个工兵班长，铁道兵的班长，就是干这个活的，临时把他抽上来，华老到了让他来负责招待他。招待华老招待得挺好，华老跟他关系弄得很好。后来这个兵不来了，说是有一次排哑炮的时候牺牲了。据说华老是非常难过，在那儿痛哭一场。后来华罗庚也说过，在乌蒙磅礴走泥丸的地方，有一位工程师出于珍惜国家财产的心情，就对他说，雷管现在成品率很低，你能不能降低一些标准，使多一些雷管验收下来？我当时认为这个事情好办，我只要略略降低一些标准，验收率就上去了。但后来在梅花山受到了十分深刻的教训，使我认识到，

降低1%实际就等于要牺牲我们四位可爱的战士的生命，这是我们后来搞优选法的起因。回到北京后，华罗庚致信毛泽东主席，谈了自己在大西南受到的教育，随信寄上了刚刚出版的《统筹方法平话及补充》。这封信在华罗庚一生中是非常非常重要的。信中写道：华罗庚同志来信及平话早在外地收到，你现在奋发有为，不为个人而为人民服务，十分欢迎。听说你到西南视察并讲学，大有收获，极为庆幸。专此奉复，敬颂教安。去年春毛泽东给华罗庚来信称他为先生，这封信已改称为同志。

他自己什么时候都带着这个小本，就放在这个口袋里，在上帝的口袋里面。其中记着一些话：一个就是他刚回国的时候，主席跟他说过的，说你也是贫苦人出身，要我们国家多培养一些人才；第二个就是主席给他写的这两封信，他记着这些，还有总理的一些批示。而且这个事情他也是真正去做的。不为个人而为人民服务成了华罗庚的人生坐标，直到多年以后，无论是对研究生做长篇谈话还是给人提词，他都喜欢引用这句话。这个话是我一生的最有名。

到1966年6月20日，受命从南京统筹方法推广现场返回中国科技大学参加文化大革命为止的428天的时间里，华罗庚离京到各地工厂、农村、部队推广统筹方法的日子就有156天，这还不包括在北京向有关领导单位汇报、介绍和与群众座谈统筹方法的时间。华罗庚在他的秘书的日记本上提了这样一首诗，既是共勉又是抒发情怀：法部同清心同热，协力同心为祖国。乌蒙山头同持居，大渡河畔共齐气。好汉太虎心胸宽，澎湃长江情意积。一砖一把一根草，云水风雷争朝夕。在1966年夏天开始席卷全国的风暴中，华罗庚受到冲击，但终究没有被打倒。

这不仅是因为身边有毛泽东写给他的两封信，而且这年的10月2日《人民日报》报道国庆节毛泽东主席检阅150万游行大军的消息，其中有在天安门城楼上的还有全国人民代表大会常务委员会委员华罗庚同志的文字。毛泽东跟他握了手，还说：华罗庚同志，你来了，好啊！这一消息不胫而走，使得华罗庚在家过了一段相对平静的日子。

1967年5月1日，在天安门城楼上，毛主席接见了华罗庚，说：哦，我们又见面了，我们的数学家华罗庚同志一向可好啊！又高兴地被旁人介绍，这是我们的数学家华罗庚同志。他的足迹遍布大江南北，他的统筹法和优选法在全国各地开花结果。他自称白发小蒲公，把应用数学变成了为工农业生产服务的工具，他被多个省份和大型企业聘为顾问。请收看探索发现下期播出的八集电视人物传记片《华罗庚》第七集《普及》。
