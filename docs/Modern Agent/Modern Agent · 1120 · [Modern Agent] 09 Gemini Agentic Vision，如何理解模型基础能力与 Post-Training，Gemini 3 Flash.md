## 总结

- 现代Agent系列回归，介绍Gemini 3 Flash的Agentic Vision工作，旨在通过多轮工具调用（如代码执行）释放模型基础视觉能力。
- 核心方法：在Post-Training中，将检测、分割、识别等原生视觉能力与通用代码工具（如Python）结合，形成Think-Act-Observe循环的Agent流程。
- 通过写代码动态生成视觉草图（如绘制Bounding Box、Cropping、Zoom），实现注意力聚焦，提升推理准确性，答案基于像素级视觉证据。
- 与SAM 3的显式视觉提示方案对比，Agentic Vision的视觉处理由模型自主产生，无需外部独立视觉工具。
- 强调基础模型预训练能力与Post-Training强化的关系，提出学术研究应聚焦于具体任务和设计技巧（如Visual Prompting），而非追求通用顶尖表现。
- 通过实际案例（如数手指、数踏板、高密度表格计算）展示多轮工具调用过程和API、抓包分析细节。
