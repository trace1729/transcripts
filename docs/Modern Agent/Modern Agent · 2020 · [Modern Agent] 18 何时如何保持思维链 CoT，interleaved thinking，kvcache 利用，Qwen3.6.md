## 总结

- 本期视频重点讲解在现代多步骤Agent执行过程中，如何以及何时保持思维链（CoT），并对比了GPT、千问（Qwen）和DeepSeek等开源模型在Chat Template设计上的不同实现。
- 全剧CoT保持（如OpenAI的'Return CoT'）能显著提升Agent在复杂任务（如ARC AGI）中的表现，降低Token消耗，并改善KV Cache利用率，是全局模式的价值所在。
- 千问3.6系列开始支持'preserve thinking'字段，允许全局保持所有CoT；而千问3.5及默认模式仅在当前用户轮次（Turn）内保持CoT，过往轮次的思考会被舍弃。
- 在单次用户轮次内的多步工具调用中，将工具执行结果（observation）编码为'tool'角色，可以保持上下文连续性，实现无缝的KV复用；若编码为'user'角色，则会被视为新轮次，导致之前的CoT被清除。
- DeepSeek的Chat Template实现与千问类似，且要求必须回传历史中的'reasoning content'，否则API会报错；其处理逻辑与行业主流保持一致。
