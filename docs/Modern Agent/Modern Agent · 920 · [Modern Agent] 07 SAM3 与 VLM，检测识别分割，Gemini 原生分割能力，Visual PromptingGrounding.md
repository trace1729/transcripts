## 总结

- 介绍SAM 3模型，可以执行检测、识别、分割等经典CV任务，并支持文本提示（text prompt）和框提示（box prompt）等视觉提示方式。
- 讲解Visual Prompting概念，即通过在图像上直接标注（如画框、点、涂鸦）作为视觉线索来引导模型完成特定视觉任务。
- 展示基于VL model（如GPT-4O）和SAM 3构建的VQA Agent示例，通过工具调用将VL model的推理能力和SAM的分割能力结合，完成视觉定位任务。
- 测试Gemini 2.5 Flash的原生多模态能力，其可以直接通过对话式交互实现检测、分割、识别，且输出包括mask、bounding box和label。
- 强调SAM 3不是VL model，其文本输入仅限简单名词短语，不支持列表或复杂修饰词，因此在构建Agent时需要规避其位置推理等弱点。
- 总结通过SAM 3可以为不具备分割能力的VL model赋予精细的mask输出能力，实现更精准的视觉定位（grounding）。
