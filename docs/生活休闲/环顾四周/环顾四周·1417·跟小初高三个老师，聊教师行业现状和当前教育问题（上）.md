你觉得这就是你的生活，你本来就应该只放20%在教书，剩下80%积极参与学校的各种活动。我们前面聊天的时候，我就感觉到了，我一定是那个工作时间最长的。因为他们一个四点下班，一个04:30下班，我们正常下班是七点，就是正常学生放学是七点。我看你这个问题是呃，这个地区的老师工资的上限跟下限对吧。其实深圳特别好的一点是小学初中高中，不论你在任何学校，只要是公办学校，你的工资只与你的职称和教龄有关，剩下的都是一样的。

### 2. 入职后心态变化：从理想到现实的转变

心态上的这个变化是怎么样？真正当了老师以后呢，一开始我是觉得这件事对我来说是一件很轻松的事，因为我考的是小学科目嘛。由于我们这边政策的影响，非师范生他只能教小学。那我觉得对于小学的这些知识来说，就随便讲讲都是很简单，就几乎每天都可以处于不用动脑的这个程度。但实际上当上老师以后，我发现这个每天烧脑的事情实在是太多了，你要面对学生、面对家长、面对领导，就每天整个人就处于一种应激的状态，因为随时随地有事情发生，你就要去处理。

我当时初一刚接手那个新初一的时候，我真的是百分之百全身心扑在工作上。不是我们自夸，我们学校是正常06:30放学的，但我那会儿基本上每天晚上都是要到8.9点左右我才离开办公室的。因为我自己刚来一个新学校，我并不知道这个备课要背到什么程度，就是当老师备课这件事情是没有最好，只有更好，你不可能什么时候说我这节课已经百分之百备好了。就是处于一种对自己的不确定预期，对学生课堂什么都不确定的状态，所以我会每天忙，晚上都忙到很晚。

然后这个事情在我带的第一轮，就是初一到初三那3年，我都是一种很拼的心态。然后等到我带到第二轮的时候，我发现其实一节课你自己背三个小时，跟一个小时其实是有一点点区别，但可能只有5%的区别，但是一个小时跟10分钟，可能就会有八九十%的区别，没有自己把自己把自己逼得那么紧了。然后再加上工作3年之后，可能因为个人的问题也要提上日程了，所以我自己的心态就变成了：我在工作时间百分之百认真的把工作做好，但是在下班时间我就完完全全的下段，可能就是这一点心态转变，我觉得是最大的。

我也是嗯比较赞同小韩老师的观点，我觉得我们受过高等教育，然后如果当时是主动选择做老师这个职业的人，其实多多少少是有一点教育理想在里面的。那么这个教育理想当你投入到工作当中之后，最容易出现的一个问题，就是有一种救世主的心态。其实我在工作之前，我就已经被一些前辈警告过，说你也只是一个老师，你不是学生的救世主。其实我对这个事情你就已经有了比较充分理性的认识，然后进入到了工作岗位，那么我也很清楚自己能对学生的影响到什么程度。

但是经过5年之后，我会发现就是越来的越认识到一个真相，就是我们老师真正能够在学生的成长过程当中发挥的作用是很小的，因此我也能够更理性的看待这个工作。我一开始也是像小安老师一样，把大部分的精力都放在工作上，跟学生关系相处的非常好，我的关系非常融洽，有很多非常感动的回忆，有非常多值得记忆的这个瞬间，这都非常好。但是这些你私人的关系，能不能变成是你作为老师这个角色，在他的身上对他的人生产生一些，不论是知识上的还是人格上的影响，这个可能等我到现在我才回过头来，看着自己的第一届学生，其实他的那个作用并没有我们想象的那么大。

所以第一次我意识到这个问题的时候，我是觉得比较失落的，因为我付出了那么多。但是我现在更理性的看待这个问题，我觉得这个反而是好事，因为我们只是一个老师，他有他自己的人生，他的人生需要他自己去探索。这样的话我既能够放手更多，同时我也能够更理性地看待这个工作，让自己的生活和工作有一个明显的界限。我明白这个界限在哪里，然后我能够更好的给学生提供更针对性的帮助，节省我的时间，其实也是在节省他的时间。

### 3. 小学老师对教育理想的态度：没有强烈理想 / 小初高学段累的程度比较：哪个学段最累？

我突然想问问一下这个小学老师，因为他们俩都在说决定当老师的这个初心是一样的，然后刚进入职场那个心态也是一样的。你的话你你你刚才其实描述了你是半推半就的进入了教师这个行业，那你在刚进入这个行业的时候，有没有他们俩这种理想主义，就是我要把所有的精力都投入到这份教书这个事业上有吗？我觉得我可能真的没有。我也是文科专业嘛，然后像我们高中同学，很多人其实毕业以后回到家乡，回到这个小城市，都会选择当老师，所以你就会发现你身边都是老师，就还是像上学时候一样，就只是嗯怎么说呢，没有那么强烈的教育理想，比如说我一定要在他的人生中起到一个多大的作用，或者说我一定要把这个孩子教成什么样，把我们的这些孩子培养成什么样。

明白，当然能理解。那刚好就是说，反正我要选择一份教师工作，那为什么最终选了小学老师？也就是引出我们下一个问题：在你个人视角看来，小初高三个学段老师哪个阶段老师最累的？其实我的教师资格证是高中语文，但是因为政策原因嘛，所以我只能选择小学老师。如果说让我自己选的话，其实我也会选择小学老师。

现在孩子我觉得初中高中青春期，他们的这些心理问题，我觉得现在是一个蛮普遍的现象，大家也都比较关注。那小学相对来说他们的压力源，就学业那方面，可能由于没有升学压力，所以学业方面的压力源可能会稍微减弱一点。而且孩子还小，没有接触太多这个网络世界啊，或者外面的东西，所以相对来说比较单纯。在与孩子相处上，我感觉会稍微轻松一点，相对于初中和高中来说。

明白你意思，你就是初中高中其实哪个类无所谓，但是在你当时那个视角看来，你觉得小学是轻松的。对，哦，明白这个问题是，你觉得小初高哪个阶段最轻松？其实我想说，我觉得没有一个阶段是轻松的。但对于我个人来讲，如果有的选的话，我还挺愿意去做一个高中老师的。因为嗯，这个其实要分你在一个怎么样的高中学校。如果你是一个比较好的高中学校的话，进入你这个学校的学生，他其实已经经过了中考的一部分筛选，至少学生的基本行为习惯可能会更好一点，我可以把更多的时间和精力投入在我的教学里头，投入在备课里头，投入在做更多的题里面。因为我是教数学的嘛，数学有很多值得研究的地方。所以如果我是一个高中数学老师的话，我觉得可能会在情绪方面稍微轻松一点，但是可能在教学方面可能压力会大一点。

高中老师你说他们最轻松？你觉得我觉得我对这个问题比较有发言权，因为我初中高中都教过。对于我来讲，我觉得这个问题要分两个层次来看。第一个，其实老师轻松不轻松，不是由学段决定，而是由领导决定的，哈哈哈是的。就同样都是小学老师，不同学校的领导会有不同的领导风格，那么老师的轻松程度也不一样。同一个学校里面，不同的年级会有不同的年级主任，这个年级主任他也有自己不同的风格，也会不一样。所以我觉得就是领导之间的差异，会比学段之间的差异会更大，这是第一个。

第二个问题，就是老师这个工作他有一个特点，就是他的轻松程度，其实我觉得有时候跟你自己的付出程度嗯，我觉得有时候不太一样。就是你付出了多少心血，你付出了多少体力上的劳动，跟你自己体感是不是轻松，这是两个问题。比如说你特别喜欢一个学生，然后你跟他每天打交道，然后你给他付出了很多，他每天都来找你，你有很多上这个教学的问题可以跟他去交流去讨论。其实你对这个学生付出是多的，但有时候你不会觉得很累。所以我觉得这个职业特殊就在这个地方，就是你实际的付出的心血跟精力，跟你自己对这个工作的轻松与否的感受，有时候就不太一样。所以我觉得这两个事情可能要分清。

但是从我自己的个人感受来讲，我现在初三，我觉得我比在高三还要更累。初三是一周上五天，高三是一天上六天，我觉得我比高三更累。因为这是这个类，是从你的获得感成就感上，我觉得这个对我的职业幸福感影响比较大。因此我的个人的感受是初三更累的，所以这是一个非常因人而异的东西。

### 4. 每周课时与下班时间：小学、初中、高中对比 / 深圳教师的工作强度与突发事件：心理危机处理

各位现在一周上几节课，下班属于自己的时间多吗？虽然我是一个语文老师，但是小学的语文老师他其实还兼任其他的教学，比如说道法道德与法治这门课也是我上，然后书法这门课也是我上，还有综合课程。就综合课程，可能因为我们学校有一些特色的地方课程嘛，然后这个呢也是我上，然后心理课呢也是我上。所以我一周算下来，语文课的话是六节，然后算上其他的，算上来一周是十节，这十节是正课。然后其他的小课比如说早读啊，午读啊这些就不去算它。

我觉得从我工作5年到现在为止，我加班的次数，比如说在放学之后还留在学校，或者是周末还要返校，或者是假期时间要做一些关于学校的工作，就是这种时刻从我工作到现在，一只手是数的过来的。所以我觉得我的加班应该算是比较少的。你这个反馈看下来，你这个小学老师好像确实不是那么的累，就是还挺轻松的。嗯是的，虽然说你刚刚报的那些课程。

### 9. 中学心理健康问题及成因：中等生压力大，疫情等影响

### 10. 名校成功因素与教师对放弃学生的态度

下一个问题是关于学校的问题，初中跟高中这两位老师的话，你们个人觉得就是名校之所以是名校，到底是因为他本身的师资好，还是他的生源优秀，就跟那个衡水中学掐尖那个之前不是有那个讨论吗？我觉得他其实是互相成就的关系，这个学校最开始最开始一定是因为有一批比较优秀的孩子，刚好碰到了特别负责任的老师，然后这个学校开始从第一届变得优秀，然后后来他们因为这个优秀招到了更优秀的学生，然后间接的显得他们的老师变成了更优秀的老师，也就是我们所说的所谓的名师。我对名师的理解是这个样子的，就是他不止能把优秀的孩子教的很好，他如果能把普通的孩子教到比他们本身的那个学习的水平要再高出一点点，那这个老师他就可以称得上名师了。所以按照这个逻辑讲的话，每一个学校里，比如说我们初三数学有五位老师，那么这五位老师其中有一位他能把他们班的学生成绩带得很好，那对于这个学校来讲，他就是这个学校的呃，如果要总结一句的话，肯定是优秀的生源更重要，但是名师他可以起到一个锦上添花的作用。

我的答案跟小花老师差不多，优秀生源是雪中送炭，名师是锦上添花，如果从一个数学的比例来讲的话，我觉得生源占80%吧，然后老师占20%。其实有一个很简单的事情，你就对比下就知道了，就是这些学校在他们力所能及的范围内，在招生上的努力比较多，还是给已经有的老师培训让他们提高技能上的努力比较多，我觉得显然是前者。但也不是说名师没有用呃，我举个例子，比如说呃，大家长期以来大家都说你们那些名校考得好是因为学生好，所以这个名校宣传他的高考成绩也好很多呃，普通学校的老师是不以为然的。那么深圳市教育局最近几年他出了一个对于高考成绩的评价，叫做增值性评价，不是看你们学校高考的学这个成绩怎么样，而是看你的高考成绩跟当时进你这批学校的那个学生的中考成绩对比，它的这个差值大还是小，比如说你中考是全市的1000名，但是你高考是全市的100名，那就意味着这个学生在你们学校在全市进步了900名，所以他对比的是这个东西。然后我们发现在这个增值性评价的这个榜单上，其实也有非常多名校的身影，就这个名校他的生源已经够好了，他们给这个已经足够好的生源还能够提高他们在全市的排名，那这个肯定是名师的作用。
