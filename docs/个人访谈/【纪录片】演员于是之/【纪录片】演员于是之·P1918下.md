# 【纪录片】演员于是之·P1918下
[视频链接](https://www.bilibili.com/video/BV1ks411G7J8?p=19)

这是一位以语言为主的话剧演员，在逐渐丧失了语言表达能力后的悲痛心情。这是于是之的灵魂之痛，是他的生命之痛。1999年3月2号，这一天是正月十五元宵节，于是之正和家人吃晚饭，突然她的身体向一旁倒去。瘦弱的夫人赶紧起身想去抱住她，可于是之沉重的身体却将夫人重重地压倒在了地板上，造成了胯骨粉碎性骨折。就在李曼仪疼痛难忍之际，忽然听到早已不能说话的于是之着急大喊了一声：不得了了，快救人哪！李曼仪忘了自己的疼痛，吃惊地望着于是之，不能说话的人居然张嘴说话了，而且声音是亮得清晰，这让李曼仪喜出望外。

奇迹并没有出现，于是之的病却更加严重。于是两个可怜的老人，一对患难的夫妻，一起住进了医院的同一间病房。著名表演艺术家林连昆记得，于是之思维和语言都病得出现了障碍的时候，他们二人一同受邀请到北京饭店参加文汇报55周年纪念活动。于是之因病失语不能发言，林连昆搀扶着于是之代替的发言。林连昆讲话时，于是之频频点头，时老师一直捏着他的手，两人手拉着手。时老师就在那旁边点头，点头完了就流眼泪。当时全场的人都为之动容，就说你们文汇报真了不起，能够使艺术家如此的动心，对你们这样的感激。当人们想到林连昆搀扶着于是之代替的发言，二人泪流满面的情景时，这是一个多么动人，又是一个多么令人心酸的场面。有人可能会想，这是一场舞台演出多好啊，当地故事演员又可以回到现实中来，而这恰恰就是真实的现实，残酷的现实。

后来这残酷的现实又发生在了林连昆的身上，他得了半身不遂，语言表达也近乎失语。他只能用左手笨拙地写出了几个让人观之动容的字：是知我很想你。洗完后，林延坤竟难过流下了泪水。一天，北京中医医院通知林延坤去住院，当他来到医院病房大楼的电梯前等待上楼时，电梯的门打开，林连昆发现从电梯中被人搀扶着走出来的竟然是于是之。林连昆激动，此时他病得也不能讲话，他向前紧挪了几步，伸出手去要和于是之握手时，才发现目光呆滞的于是之两眼望着前方，根本不曾看见林连昆一样。于是之此时病得不认识任何人了。林连昆看着于是之，浑身激动地颤抖着，眼中流下了两行热泪。当林连昆来到病房后，才得知自己等待的这张复院的病床，竟然是于是之住的床位。

这好像是上天的有意安排，让这两个同病相怜的人不但在楼梯前擦身而过，还让林连昆住到了仍然留着于是之余温的同一张病床上。林连昆坐在病床上，耳边响起了他和于是之在一次联欢晚会上表演的叫卖声：阿修，消尽人类，一年亏眼前。又浮现出了他和于是之二人一同参加运动会时的情景。在于是之任北京人艺副院长的八年之中，他绝无仅有的一次作为运动员参加了北京市机关运动会。于是之踢足球是一件让人无法想象的事，您看于是之踢球的姿势和神态，完全可以被评为北京人艺的足球先生，但让人担心的是，他可能会连球带自己一同踢飞出去。于是之打门球的技术并不比他踢足球高，从他一脸无奈的样子就可以看出。当他看到林连昆把门球打出了界外时，于是之心中一定在说：这水平比我也强不到哪去！

于是之静静心，定定神，信心十足地将球打入了球门。于是之走路的样子，一下子脸上充满了自信和豪气，他一定在想：林连昆今天和我比赛，定输无疑。最后一击求出借赖，让刚刚兴奋起来的于是之尝到了交兵必败的滋味，他只能用手无奈地抓了抓，走出了赛场。从此于是之犹如走出了人生的赛场，从人们的视线中消失。于是之被脑血管病和老年痴呆这一对病母折磨得再也没有力气行走了，成为了一个不能思想、不能与人交流的人。于是之从此彻底丢下了手中的笔记，忘却了他厮守了一生的书籍，他再也没有精力去想象一下自己倾注了全部生命的舞台了，还有此，走进了一个人的沉默世界。就这样静静地躺着，他太累了，累得他一觉睡下十多年都未曾醒来。他还明白的时候，他说：我要先走了。你肯定很难受，说我说你肯定很难受，他说你要是先走，就说我要是先走了，他说那我就更不得了了，他说我怎么办。我说我们俩人能在一块的时候，我说把所有的我们俩人知道的东西都都说，我说咱把这材料都给他集住都记下来，这将来不管是是谁。

你肯定很难受，说我说你肯定很难受，他说你要是先走，就说我要是先走了，他说那我就更不得了了，他说我怎么办。我说我们俩人能在一块的时候，我说把所有的我们俩人知道的东西都都说，我说咱把这材料都给他集住都记下来，这将来不管是谁。

先走或后走，我说，我们都可以，就看到这些东西，我们也都互相就都记住了。于是之离开舞台已经很久很久，可是观众和剧院并没有忘记他。2007年是于是之的八十大寿，北京人艺的领导带着鲜花，代表剧院，代表观众，来为于是之祝寿，北京日报用通栏的大标题发表了文章，贺于是之先生八十大寿。于是之的演剧生涯，以及于是之一生的归宿，所带给人们的是那样的惆怅，一位以语言为主要表现手段的艺术家，最终丧失了语言能力，人生之悲剧莫大如此，几十年的光阴逝去了，于是之用终身热爱的话剧艺术，记录了他生命之中永不会再来的黄金岁月。

1978年，51岁的于是之作为特邀人士参加了中国人民政治协商会议，1982年，于是之参加了中国共产党北京市第五次代表大会。1982年，于是之参加了中国共产党第十二次全国代表大会，1985年，于是之当选为中国戏剧家协会副主席，1987年，于是之参加了中国共产党第十三次全国代表大会，1988年，于是之被选为第七届全国人大代表。1989年，于是之被评为全国先进工作者，1989年，于是之当选为北京市戏剧家协会主席，1992年，于是之参加了中国共产党第十四次全国代表大会，1993年，于是之被选为第八届全国人大代表。1993年，于是之荣获了中国话剧艺术研究会第一届振兴话剧奖荣誉奖第一名，2005年，在中国电影百年之际，为表彰于是之在电影表演艺术上做出的突出贡献，被评为中国电影百年百位优秀演员。2007年，于是之因对中国话剧事业做出卓越贡献，被推选入中国话剧百年名人堂，2007年，中国话剧百年之际，中华人民共和国人事部、文化部授予于是之同志国家有突出贡献话剧艺术家荣誉称号。

简于是这样的，不但首席，而且就是一种偶像，在我心目当中是伟大的演员，有些境界你一生都无法达到，就是他是高不可攀的，代表这个领域的最高水平，或者说最高段位，就是你心里就有一个标杆，前辈的标杆，史志老师的标杆，在这作为演员来讲。特别对今天有现实意义的，就是他是一个学者型的艺术家，他文化修养，中国的文化修养，各方面他是比较深的，他真正的称得上是一个学者演员，那你能够创造一两个、两三个永远活在观众心里的艺术形象，你就是最高的大奖了。所以他完全可以自慰了，施芝同志一共塑造了29个舞台艺术形象，我觉得这些形象可以讲是充实了我们现代话剧经典的舞台人物形象的画廊，他在继承剧院的传统，而且发扬剧院的传统上特别大的贡献。给剧院积累了一个阶段的剧本，《世事》是真正的把北京人艺的这个传统在新的事情发展，《余思珍》呢，它是把画剧演员的那个演员文化提高到了一个新的高点，这个是它的一个功绩，所以它后来成为一个一个标杆，一个代表者，一个整个一个时代的领军人物，是绝对是有道理的。

我希望修昔世子老四，在艺术很难有独创的年代，他完成了独创，在很多人走向平庸的时候，他保持了过去，无论从立功立德立案，他都是一个完美的艺术家。做人做戏到如此地步，也是我们话剧事业的一个幸福，因为我们可以从他身上总结出很多很多东西来来继承来发扬，我觉得这个同志啊，是可亲可敬也很可配的一个人，于是之是。一大工程，一大英雄，一大天才，一大演员，于是之用他毕生的心血，塑造出了一个个有血有肉、性格鲜明、各界特色的人物形象，成为了中国现实主义话剧人物创作画廊中的一座座丰碑。

于是之是中国话剧民族化的亲密者，他也是焦绝尹先生创立的中国演剧学派的实践者，他演出的茶馆走向了世界，让世界了解了中国的话剧，同时也让世界了解了于是之。于是之虽然早已离开了令他浑绕梦迁的舞台，离开了关心和热爱他的观众，然而于是之的精神，他的艺术，他的人品，他的修养，他的寻识，他做人的气节，却永远地留在了人们的心中。于是之，用他的智慧与创造，人格与品德，赢得了人们对他的敬仰与尊重。人们永远不会忘记，这位为中国乃至世界戏剧艺术做出过卓越贡献的人，演员于是之。文艺是一种梦想，鼓动希望之分，牵引精神。
