- 主观是纯粹的内心声音，不受人和物的影响；客观包括裙带信念、功绩信念、他人、物体和身体等物质层面。

### 2. 定义主观与客观：内心声音与外界一切

然后我把这些个概念串起来，就是我们是一个人，然后我们一般一生中会碰到两种东西，一个叫做其他的人，一个叫做物。然后我们这是我们的脑子嘛，然后我们人和人之间产生的脑子里的东西是裙带信念，而我们人和物产生的关系其实是功绩信念。裙带信念和功绩信念我在前面的视频中非常简单的提到过。其实我们的大脑是为了我们的利益而设计的，它不是为正确而设计的，那么它就会有两个维度，一个是实用，一个是社会性。实用是指什么呢？就是我们去认识我们身边的物，认识客观世界，然后这个规律越正确，越对它就越实用。而我们的社会性是指我们跟人相处的越好，这个社会性越高。

所以呢我们会出现一些内容，这个内容如果实用性远大于社会性的话，它就是功绩信念；而如果社会性远大于实用性，它则是裙带信念。中间会有一个比较模糊的部分，它就是分不出来到底是工具信念还是裙带信念，它都有，就它既有实用性，它又有社会性。

然后呢我们脑中纯粹的只有我们自己的声音，就是内心的声音，我们觉得是什么样子的，是不受人和物的影响，不不受身边的人跟你说，唉，这样不行的，然后如果你不按他的去做的话，就会受到社会压力，然后你就会去改变自己的想法。或者说不受物的影响，就是说没办法，就是突破这个物理约束的，就有些东西你暂时没有掌握这个物理的规律，然后你就做不到的东西，这部分也是不算在内的，就是除此之外，就是完全你内心的声音，这就是主观的内容。然后除此之外，只要是内心声音之外的东西，全部都是客观。

所以他的客观他其实是裙带信念，然后功绩信念，加人加物，还有你的身体之类的东西，他全部都算，只要是内心声音之外的东西。然后这个主观的内容加在一起就是你脑子里的东西，他其实是精神层面的；而人家物加身体其实是客观的，这个准确来说是物质层面的。

好我们分清楚了这些东西之后，你知道这个概念了以后，就会有一个特别大的变化，就是意识到什么才是客观去把它分开来。有的时候我们相信的东西，它不一定是我们内心的声音，他不一定是他可能是就是别人跟你这么说，听别人这么说，或者是你最重要就是制约，就是就是你来自于语言上的设定。就比如说我之前举的例子，就是我爸爸妈妈说我一点方向感都没有，然后我就觉得自己没有方向感，但实际上当我去练一练，相信自己有方向感，然后去练一练，其实我还还算有方向感。就是说我没，然后我就信了，信了也这么做，然后事情就变成这样了。

还有一个就是身边的人，就是其实是来自于模仿，就是有样学样，你做什么事情其实蛮有你身边的人的影子。哪怕说你的亲人有些方法，做事的模式你是不认同，但是你后面的时候会发现，虽然你心里是不认同，你觉得他这样做的不好，但是你的底层逻辑有很大一部分会跟他们很像，以及特殊事件，就是给你留下非常深刻的印象的外界的事件，然后会给你带来一些影响，这个特殊事件大概率是这个人和物都可以会有的。所以这些制约其实不是你内心的声音，就是各种各样的东西，他都可能不是你内心的声音。当你分清楚这些之后，可能你有一些非常困扰你的东西，你就会就会变得清晰起来，就是意识到哦，这些东西他其实没有这个东西，独特和独一无二以及重要，所以你就会想着去摆脱它的束缚，别人跟我怎么说，哎我先不在乎别人世界是什么样，然后一些东西给我带来的一些影响。

### 4. 摆脱束缚：利用客观打磨主观，实现主观自由

我先不让它影响我内心的声音。比如说我现在考试的分数就是不理想，我考研就是考了两年，我就是考不上。但是不要影响你内心想去做、想去干什么的念头。去摆脱这个的束缚之后，你就可以开始利用客观去打磨主观。是什么意思呢？就是说这个东西和你这个客观世界、和你所想的不一样，然后这个人和你预想的不一样，他们之间不能达成协同的时候，不要去放弃自己的声音，也算一种打磨自己的主观。或者说知道自己内心声音真的要什么东西，为了这个要什么东西而去与人更好的相处，去提升自己的社会性，以及提升自己脑子里念头的实用性。

也就是说你对这个物理的世界的把握，如果是社会性的话，就是人文社科；如果是实用性，就是自然科学。就是这两项知识的方面就是裙带信念和攻击信念的内容。你可以提升这些内容的把握来去利用客观，然后打磨你的主观。无论如何都在追求你内心的声音，然后去实现主观上的自由。主观上的自由就是听听你内心的声音，从心所重新。如果你想要客观来给你主观的自由的话，是不行的，因为主观真正的自由是聆听内心的声音。

你内心的声音是不受客观影响的，其实你受客观影响的时候，其实是你授权给了他。就比如说哪怕说给你放进监狱里，你内心怎么想，他是管不了你的。他可以限制你的身体，他可以改变你身边是什么人，他可以改变你的记忆。甚至就比如说在一人之下里面，曲同他有双拳手，他改变了马先红的记忆，但是马先红内心的声音他还是拿着的。我还挺佩服马先红，就是记忆这么重要的一段东西，他被篡改了，他还是聆听内心的声音，还是去感受它，这其实还挺厉害，这就是主观上的高度的自由。

而主观不能给你自由，他只能给你死亡，就是把你灭了。你的身体和你的这个精神全部灭灭，食就是这两个部分全部灭失，他只能给你这个。但如果你想要你主观内心的声音的自由，他给不了。所以意识到这件事情的时候，就要放弃从其他的人物和知识那里去试图拿到主观的自由，这个东西只能你自己给自己。
