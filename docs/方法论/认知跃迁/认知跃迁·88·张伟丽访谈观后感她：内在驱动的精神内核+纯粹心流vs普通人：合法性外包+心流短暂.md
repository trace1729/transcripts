大家好，我是曦禾。今天想分享的内容是关于“合法性外包”的一个词。这个词大概也是AI编的，但我觉得用来描述这个话题会比较精准。之所以要去分享这个内容，是因为我最近看了张伟丽的访谈，然后提出了一系列的问题——就是我会对他实现一个别人认为不可能的目标，再到他去卫冕，再到会有更大的目标，我会有相似的体验。我会想知道，人一定要有目标吗？当他目标一步步变大之后，会不会因为实现巨大成就之后，就没有想做的事情，而空落落的心理？这是不是有害的这个问题。然后去跟AI进行了一系列的深度协作去聊，翻了很多我之前的经历，想去理解我过去体验到的事情是为什么是这样的。而这个合法性外包就是这一期要分享的内容。

可能现在看起来会有一点点抽象，但是我后期就是这期内容录完了之后，如果我能以更加好理解的方式去表达这期内容的话，我会重录，或者说再更一期之类的。毕竟AI的通病就是他会捏一些抽象的概念，让我觉得很不舒服，这也是我现在和AI写作的时候需要改变的东西。如果你感兴趣的话，就跟我们一起看下去吧。

首先第一个最重要的问题，就是我会出现一种——就是我在做的事情需要得到认可、认同，才是值得做的，才是有意义的。然后在AI的概念里面，他提出来这是一种“合法性外包”。然后这一段我们会回答：合法性外包是怎么来的，它是怎么发作的，我以前针对这个东西想做的解法为什么不起效果，以及怎么去真正地解开它。

这个问题的根源，就要讲到合法性外包是什么了。在这里其实是包含两种形式，一种叫做内化的审判者，一种叫做外部合法性来源。我有去和AI去聊，让他去给我拿出心理学的映射概念。但由于AI自己捏了词之后，他想去找传统心理学理论的时候，会有很多的概念，比如说超我、价值条件、应该的报证、内设调节，还有内化、否认环境等等各种各样的词。然后他会总结出一个词来去描述它。包括这个外部合法性来源也是这样，以及后面一个非常核心的概念叫心流，它也是有很多的概念，然后选一个有描述性的概念。

首先这个内化审判者，他的定义其实就是内心的特定质疑。它会有一点点像我之前更新的“exercise potential”，但在后续我会概念辨析的时候再去区别。就是他会质疑什么呢？质疑这个有没有意义、有没有用、是不是应该做的。这种质疑出现的时候，就会拿外界的标准，比如说有没有产出、会不会带来财富、别人认不认同、你这个技术顶不顶之类的，来衡量自己正在做的这件事情的有效性和意义。

但是虽然他拿的这个标尺是外部的，但发出这个质疑的是自己，所以是内化的审判者。然后全方位的去理解这个概念，其实可以通过心理学上已经有的概念。比如说超我，超我就是内化的父母权威，他会偏向于道德审判。但这里我们讲的其实更像是现实审判，所以超我不会完全地覆盖我想聊的这个部分，所以它更像是泛指内化审判。还有价值条件，比如说从小被有条件的对待，所以内化了一条自己必须满足什么条件才配存在的价值标尺。其实这个话题有点像之前看到有一本书叫做《无条件养育》。

### 2. 心理学映射：超我、价值条件与动机连续谱 / 外部合法性来源及其影响

我感觉很多家长真的做不到说无条件的爱孩子。其实当爱是有条件的时候，他已经不是爱了。所以当它被包装成爱的时候，嗯，会给人带来一些不太好的影响吧。这个教职条件就更像是内化审判者的尺子或者是标尺。而应该的暴政则是会有内心有一套我应该的命令系统。我应该有用，应该坚强，应该考得上。这些应该会像暴君一样，强制人没有满足，就会自我惩罚和否认。

这种应该是道德衡量上的，但是我实际生活中出现的这个内化审判者更加的不好的地方是，他会去质疑你的现实是不是真的。就比如说比如说自己真的感觉到自己有抑郁的症状了，而外界会和你说，你不是抑郁，你是脆弱，你只是自己脆弱。然后拿这个当呃挡箭盘，然后内心也会出现这种怀疑去说自己是不是真的。所以这个词汇符合这一个小小的维度。还有内设调节，这是来自于自我决定理论。他说就是做事的动机不是出自于内心，而是出自于内化进来的外部要求，没有把他真正的变成自己，而是像一个外来物一样起支配作用。如果做了的话，就是逃避内疚，索取认可。如果没做的话，就会内疚和惩罚。

他这里讲到有一个动机的连续谱，就是第一个阶段是外部调节，有纯粹的奖惩，为了奖励和惩罚。内设调节则是内化了外部要求，但没消化及认同。调节的话就是理解了价值部分变成自己，我知道有意义，所以我选择它整合调节是完全变成自己的一部分，自然就做和自我一致，以及内在动机，纯粹是为了这件事本身读书读得快乐，不问有没有用。这个是一整个环节。然后我觉得这个连续谱是比较像的。我不是那种纯粹的外部调节，我更像是一个内设调节的状态。但我之前在生活中的某个时刻有体验到纯粹的内在动机，但是他还是会被打回去，大概是这样。所以这个理论也有一定的解释效果。还有内化否认性环境，就是真实体验被他人反复否认，内化了，这个否认在独处的时候会否认自己这些概念呢。它实际上会对应着说我去判断自己的意义感的那个标准是价值条件。

我应该怎么做，是内化的暴政的概念。然后自己现实不算数，不不承认不对等的时候是内化否认性环境。以及超我则更像是内化审判者。我之所以没用超我这个概念作为最大的标题，就是因为嗯光靠这两个字我识别不出来，所以我才用了AI的概念。然后此外还有一个叫做外部合法性来源，他是一个能预先回答我做的是有意义的外部结构。就比如说考研中考高考，他们就可以预先回答自己学习读书是有意义的。钱或者说父母的认可啊之类的，他会帮你回答这件事情有没有意义，他能让别人开心之类的。只要不是来自于自己的，然后他发挥作用的时候，就是当你有一个外在的外部的合法性来源的时候，你内心对自己的审判就会被是预先拥有的答案给压住，你就不会去怀疑自己。

他的例子就是考试和排名，他会预先回答自己学习是算数的。父母的认可会预先回答努力是算数的。但是当外在环境变化的时候，这个来源被撤走的时候，内心就会出现对自己的审判。然后在心理学上的概念映射就有拉康的大他者，它是一个象征性的程序，就比如说社会的规则，权威的目光评价体系，它会让你做的事情是呃合理的，算术的就是被认同，就是算术不被认同，你就像被空置在那里。如果结合我自身的经验的话，就是在一个考试体系中，就相当于在大他者的目光中，就会觉得自己做的是有意义的，合理的被授予了合法性，不用自己问。但是当成绩不好的时候，没有其他人认可的时候，就失去了合法性来源，那么内化的审判者就是内化的大他者开始运作。

但是大他者他有个不准确的地方，就是它是一个抽象的，而场域可能会更像是呃这个概念。但为了这两个概念对称，所以我还是使用的是外部合法性来源这两个概念。然后这两个共同组成了合法性外包。不论是由外界来定义自己做的事情是合理的，有意义的，还是拿着外界的评判标准来审判自己有没有意义，他都是把合法性外包了。存在着问题的时候就会出现，就是有多少人认同你，你都不会感觉到舒服。你做了多少成绩，你都不会感觉到踏实。他的问题是出在这个机制上，也就是真正有意义的，有价值的，是需要被确认的。它不是出于内在的董洁，而是出自于内化进来的外部要求。

### 3. 内在与外在错位：痛苦的结构

还没有把他变成真正的自己，然后在心里起着作用。我觉得这个状态最符合的就是这个自我决定理论里面的连续。不不，我感觉我今天要分享的所有的内容都是为了让我自己认识到哦，我在这一个内设调节的环节，然后我想要实现能够拥有内在动机的部分。而且我觉得这个部分会很大程度上帮助我更好地搭建之前所讲的休息和奖励系统里面的奖励的部分。因为当我去搭建休息和奖励系统的时候，虽然奖励库里面已经开始填充一些东西，但我最近再去把它做成网页工具的时候，意识到好像事情没有那么简单。我好像之前没有怎么真正的去奖励过我自己，我甚至之前都没有很多的去聆听自己的感受，更加不知道做什么东西是能够让我自己感觉到被奖励。奖励更像是内在的认可，我自己奖励自己，像是我自己认可自己，然后给自己一个特殊的让自己开心的东西。

所以然后我们接下来再讲这个我出现的这个问题的结构。就是当这个内化的审判者出现的时候，以及我没有外部的合法性来源的时候，它会出现一个内在的真实情况和外在的认可不对等的感觉。我把它命名为错位。就是我内心真实发生的东西和外在的认可程度都是真的，但是他们是矛盾的，会让我痛苦。这个痛苦不在于说其他人认可我的程度高还是低，而是他们没有匹上。我其实是可以接纳别人不认可我的，但我不能够接纳说他不认可我，但又不承认我内在真实的感受。然后表现出来的关系相对亲密的状态，他们就会出现一个错位，会让我觉得很不舒服。

然后举一下例子，就比如说亲人之间表现得亲密，但是他会否认我真正的感受。就是我们之间好像会交心啊，会去说自己内心真实的感受，但他又不承认我真实的处境。就是我自己感受到我自己的处境是真的，但是呢我也感受到他跟我是很亲密的，但是呢亲密的人不认同我真正感受到的东西，他会让人非常的难受。就好像对自己非常重要的人在否认自己感觉到不舒服是假的一样。所以这里就很符合，就是真的等于被别人确认的。这种痛苦就来自于我自己内心开始聆听我自己了，但我又没有完全的摆脱外在认可，就是依托于外在认可来确定这个是真的有意义的、有价值的，然后这一个过程的错位会让我不舒服。

第二个就是做事情的时候的一个例子。就我在看书，然后在用费曼学习法，这是我内心发自真心想做的事情，但是呢我内心又会去审判自己，说你这个看书有没有用啊。一方面我做这件事情的时候是真的很开心，但是呢内心对他的质疑好像又是真的，然后左右打架吧。就是我做事情的时候开始聆听自己内心的想法，身体真正的感受，但心里面用外部环境的标准去审判自己的动作，一停下来，这个有没有用。这个不知道大家有没有过感受，就是特别是老一辈一点的家长，你你在做一些什么事情，然后还会过来问你这个有没有用啊，赚不赚钱啊，花里胡哨的什么的。虽然我们在面对他审判我们的时候会不舒服，觉得我和他之间有代沟，但是当你意识到自己有的时候也会问这个赚不赚钱啊，有没有用啊的时候，倒还挺难识别出来的。

对，还有一个例子就是重大的目标实现了，人从心流状态里面出来了，但是人还在心流状态没了。就是外在的处境，就是你实现了非常重大的目标，但是你内在已经没有那种心流体验了，就相当于你得到了外在的认可，但是你没有得到内在的认可，他们存在的一个错位，你就会有空落落的感觉。这些都是这个结构出现的一个表现的例子。

### 4. 症状与代偿行为

症状的话就是直接的影响，就是会表现为心里空空的。这种空是你不在心流状态了，所以你的状态崩塌了。就好像考上了研究生之后，你会经历一段空空的状态，你会想去做题，你又不会去做题，或者每一次你学业有大成的时候，然后会想要去做点什么，但又觉得没啥，就那种很模糊的感觉，但是又觉得不舒服，想忙一点，但又忙不住，忙不进去，不能再像备考那时候那么投入了。只是这个的直接影响。而长期的影响就是，当你脑子里既有内化的审判者，就是自己对自己的，用外界的标准质疑自己做事的有效性，以及你聆听自己内心的声音，真的有自己想做的事情的时候，你的意志会在中间去压住内化的审判者那边。

然后让你去做你自己真正想做的事情，这个动作会让人比较累，所以你不一定能撑多久，你就会坍塌。举一些例子，或者说去讲一下这个东西能解释什么。就是为什么你有的时候做一些事情，开心了一段时间，你又做不下去的话，就是因为压是有体力的。你去压制一天，压制一周总有力竭的，那个时候你内心就会审判他有没有用，这一段时间是你能撑住的时间的长度。

而且我之前初中的时候以及考研的某个阶段，会出现纯粹的这个心流状态，其实是因为那个时候我考研的意义，还有中考的意义是有外部合法性来源的，就是我父母的认同啊，然后这个东西本身在社会上就是有含金量的，他会分摊我的压力，就是他帮着我去压制内心的审判。这样子的话就是除了我自己去压制它之外，还有外部的合法性去压制它，然后我就会去做我自己想做的事情。但是当这段考试结束了之后，你就会状态坍塌，又从就是做想做的事情里面出来，以及去解释为什么做不下去，是默认的结局。

就是因为我们内心一直会有内化的审判者，拿外在的标准去审判自己做事有没有意义，他不需要每天都赢，他只需要在我缺失外部合法性来源，或者说我自己内心压不住的时候，就会让我夸他，这事情做不下去。而且他这里讲到就是这个结构下，不会从更会压制自己内心的内化审判者，转变到就是我无需再压制内心对自己的审判。这个点其实是我在看张伟丽的访谈的时候，给我带来的非常大的启发，一丝都没有，他可以和那个采访他的记者解释为什么自己是无名小卒的时候，依旧相信没有怀疑过，但是你问我会答，但你不相信，我也没有那种一丝的冲动和意图去向你证明他的那种感觉。因为张伟丽内心就没有质疑过自己，他从来都没有去想要去压制内化的审判者，因为他心里就没有这个东西。
