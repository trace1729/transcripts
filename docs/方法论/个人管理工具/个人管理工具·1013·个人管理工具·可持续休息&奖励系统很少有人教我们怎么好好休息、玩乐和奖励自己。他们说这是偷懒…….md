## 总结

- 系统框架包含长期休息习惯（作息、日常事项）与短期休息选择（休息库和奖励库），本期重点讲解短期部分。
- 休息是无条件的基本权利，奖励是任务完成后的额外激励，两者不可混淆；区分它们能避免自我克扣和失去激励意义。
- 短休的关键在于将难以量化的产出目标转换为可量化的投入承诺（如每天10个番茄钟），以此获得休息的底气和正循环。
- 休息库按功能分类（生理重置、感官切换、心流创造、自然空间、连接、探索成长），核心原则是“做相反的事”，并区分真休息（对症、进入心流）和假休息（刷手机、躺平）。
- 奖励库是休息库的升级，采用即时、不定大饼原则，按心理重量设置；发放规则包括信号识别（节律、身体、预警）和强制窗口，防止克扣。
- 系统强调实时监测状态（追踪系统），及时止损，把愉悦作为北极星，鼓励自我关怀和系统性选择，而非苦行僧式坚持。

### 2. 长期休息习惯：作息与日常事项 / 番茄工作法的休息机制与局限 / 短休要解决的问题：目标不清晰与恶性循环 / 愉悦休息的规律：活动层与结构层

然后第一个要讲的部分就是长期的休息习惯，包括就是你要去睡觉还有起床，你作息早睡早起的这个流程你是需要去定下来的，这样的话可以帮助你。当然如果你睡不着...

你可能需要把睡觉当做一个接纳群的内容。但是如果你能轻松入睡，那你可以有一些小习惯列入支持，然后逐步去执行。还有一些日常事项，也是帮助我们能够比较好地工作休息。因为人除了要工作之外，还要有日常生活，日常生活的具体事项就需要去做。比如除了吃就是睡，还要上厕所；如果是戴眼镜的人，要洗眼镜，这样可以保养眼睛等等。这些就是一些极简的日常，用很聪明的方法去备菜，我们就可以轻松吃到香喷喷的菜之类的。这些我会在后续再更新。

还有一个休息习惯叫做番茄工作法，就是内嵌在工作流程里面的。它是说你工作25分钟，休息5分钟，这5分钟的时候要进行一个微休息。而当工作四个番茄钟的时候，要进行一个阶段性的休息。这样的休息顺序会让你能够比较好地充电和放电。但是它只能用于大概一天之内，如果你一周每天都按番茄工作法这样工作，你会力竭的。所以就要做到有一个短期的休息选择，就是在番茄工作法的基础上，我们要去叠加奖励库和休息库的内容，并且用追踪系统来感知自己的状态：我该不该休息？我能不能获得奖励之类的。

这里我要开始讲这个短期选择的系列。它要解决什么问题？就是我之前有一个恶性循环，我学会番茄工作法之后，就会高强度工作，每天都按这个周期来工作，但是休息是不够的，就会出现情绪低落，然后被迫放假的恶性循环。这里的主要组成是，首先我的目标不清晰、难以量化，就会出现觉得做得太慢、达不到效果、舍不得休息的情况。这部分我在之前的视频里面有讲到过，就是任务优先级的内容。还有我们可能会出现探索期和解决期的区别。有时候目标不清晰、难以量化的重点，在于说你目前的人生阶段在切换，在转型阵痛期，你也不知道自己的目标是什么，你还在探索，还在试错，所以这时候就会出现这种困难。

所以他要干的事情就是把无法量化的产出目标转换成可以量化的投入承诺，也就是番茄钟中造出任务完成的体系，然后说服自己今天可以去休息、今天要休息多久。而投入的承诺就是番茄钟的内容，具体可以看我番茄钟的视频。番茄钟就是一个非常棒的单位，它不仅是25分钟，而且是25分钟的专注投入，它是把任务完成量、精力和时间三合一的一个单位，所以对我来说效果非常的好。

第二个就是说愉悦的休息是有规律的，它分为两层。一个叫做活动层，就是你会不会休息，你知不知道什么是真正的休息，也就是我接下来会讲的休息库的内容。什么活动会让你感觉到放松脑子、放松心情、放松精神还是放松身体，什么活动能达到这些效果，达到什么程度，这个是活动层的内容。我已经会做结构层的了，就是你需要有固定的可信的休息时间和空间，在某个时间段雷打不动地休息，而不是有空再歇，因为你可能会克扣自己。此外就是需要有那种自在感，就觉得自己该做的已经做了，我可以休息，而不是觉得我完不成、不能休息，这是结构层的内容。

所以达到愉悦休息的规律，就需要你有丰富的休息方式来提升休息质量，以及休息时间和空间以及自在感，来让你这个休息有一个位置可以放，有心理上的底气以及时间和空间的支持，这是结构层的内容来达到这个休息。如果没有休息的时间和空间，没有任务完成的底气，躺在那里也会有负罪感。好急哦，我想工作，我要休息，我又想工作，就是这种很纠结的状态，不知道大家有没有。

### 3. 缺乏自我关怀：不允许自己休息 / 个人经历：考研苦行僧状态与后遗症 / 系统执行要点与底层逻辑 / 结构详解：投入承诺与番茄钟目标设定

然后第二个点就是缺乏自我关怀，就是不允许自己休息。这个点其实我觉得还挺常见的，就是知道自己喜欢选择，却没给自己选择的机会。我们需要从克扣自己转向给自己系统性的选择，去识别什么是在克扣自己、苛待自己，就是不允许自己休息、不配奖励，把本来应该属于我们的休息设做奖励，让基本诉求变成交易的一部分，然后平时过得苦巴巴的，让休息的时候去吃一些正常的食物都变得很美味。

这其实是克扣，它是需要去用追踪系统去提前抓住的，而不要等崩盘。至于怎么提前抓住呢，就是你要自己在阅读追踪系统里面捕捉自己的感受、自己的成就感、平静的喜悦感，还有奖励。这三个维度可以帮助你意识到，如果我我不开心，也许是我有些地方克扣了自己，会没有休息；如果没有成就感，是我没有底气，可能我就不想休息；以及我每天给自己发奖励的量是多是少，来去识别我是不是最近这个情况，是因为奖励多还是少了而产生的。

然后克扣我再细讲一下，因为这个对我来说真的还蛮多见的。以前我考研的时候，我会把自己转换成一种生存状态，我会想要自己吃的均衡、营养均衡，但我不会想要说追求太美味，能吃就行，相对开心就行，然后要方便，去食堂要快。然后睡，我也希望自己睡得好，然后及时的去上厕所、去洗眼镜，这一切都是完全服务于说，我希望我坐在那里做题的状态是好的。然后让我每周二下午的公休，就是我给自己设定的休息时间的时候，我会去吃一些我要跑出校门去买到的食物的时候，我靠好好吃。但是我意识到，原来是我日常的时候，把自己的常态生活要压得像是一个苦行僧状态。

当然我那时候还挺开心的。但是就是一旦脱离了像考研这种有明确目标的状态，像应试啊、期末考试啊、证书的考试啊，他是有一个准备期的嘛，他最多说半年一年，然后几个月三周都可以，像这样苦行僧式的去做其实是可以的，但是它不能持续太久，持续太久身体会垮掉。因为我个人是经历过考研二战的，考完了之后我就发现我的身体极度的虚弱。我当时就意识到，自己好像在这个工作系统上其实没什么问题，但是在休息系统上是有问题的，就是我不知道怎么休息，我不知道怎么平衡工作和休息。所以只要这样不健康的系统运行的时间长，你就会像一个放电放太多、充电充太少、工作时间太长的一个电池一样，亏电状态不佳。

这就是这个系统想解决的问题，然后它执行要点就是记住我们状态差也是值得玩的，希望从不准自己玩、越耗越差、崩溃的痛里面反推出来，去及时的止损，去执行自己的保底，而不是奖励。此外就是有的选会让人非常的幸福，因为固定的休息时空会给你确定感，而可选项会给你带来掌控感，然后在这套制度里，我会注意去增加我自己的可选空间，然后让我自己开心起来。于是这套系统的底层逻辑就是番茄钟达成了，就意味着我的任务完成的很好，很有底气，所以就可以解锁休息不欠债的状态，然后让自己本来就有的享受能力自动上线。
