## 总结

- Attention Sink现象：在多数层尤其是中后层，所有token的query与序列第一个token（BOS）的key计算出的注意力分数异常高，原因在于softmax强制归一化时需将概率质量卸载到固定的默认位置。
- PTH（Previous Token Head）模式：模型通过将前一个token的信息搬运到当前token的残差流中，使当前token的表示蕴含相邻关系，从而支持局部依赖处理。
- Induction Head机制：在模型深度的1/3到1/2处出现，模型通过识别ABAB模式并复制下一token来进行高效预测，这是上下文学习（ICL）的核心基础。
- 注意力分数矩阵满足下三角特性（causal mask），且自然语言的局部性导致对角附近的值较大，远程依赖随距离震荡衰减。
- 通过构造重复随机序列等探针，可激活并可视化识别attention sink、PTH、induction heads等典型模式。
- 代码实现需基于eager模式获取attention score，遍历所有层和heads后，用均值等度量将矩阵坍缩为数值，以量化识别各模式。
